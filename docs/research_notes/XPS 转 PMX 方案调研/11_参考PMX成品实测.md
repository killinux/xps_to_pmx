# 11 参考 PMX 成品实测（"18" 系列 vs 源 XPS vs 用户旧转换）

> 目的：插件默认值要以实测为准，不靠"坊间说法"。本篇逐项测量本机上一组完成度很高的 XPS→PMX 成品（"18" 系列，疑为同一位熟练转换者所作），并与其**同模型的源 XPS**（在 Blender 3.6 里用 XNALaraMesh 无头导入后测量）以及用户自己的旧转换做对比。
> 全部数据由脚本生成（只读打开模型文件），脚本与原始输出在会话 scratchpad `pmxref/` 下（`dump.py`、`scale_pairs.py`、`lower_body.py`、`arm_weights.py`、`physics.py`、`bl_xps_dump.py`、`bl_blend_dump.py`、`out/*.md|json`）。
> 坐标约定：PMX 原生坐标（Y 向上，模型面朝 −Z，角色左侧为 +X）；XPS 在 Blender 中导入后按 (x, z, y) 换到同一约定再比较。长度单位：PMX 单位（mmd_tools 默认 1 单位 = 8 cm，即导出倍率 12.5）。

## 0. 结论速览（详细证据见各节）

1. **尺度：既不是固定 12.5，也不是"总高归一到 20"。** 三组同模型配对得到 PMX/XPS 因子分别为 **10.9376 / 11.4247 / 12.2246**（=12.5×0.875 / ×0.914 / ×0.978，网格整体等比、各轴一致到 4 位小数）。但 6 个 18 系列模型的 **左腕/左肩 高度 = 16.99 ± 0.04（变异系数 0.22%）**，是所有解剖标志里最一致的一个（头顶 20.60±0.17、眼 19.38±0.12、总高 21.37±0.75）。推断其规则是"**把肩线放到 ≈17.0 单位**"（等价于头顶≈20.6）。另外**每个变体都把最低顶点贴地（Y≈0）**，脱鞋变体会整体下移重新贴地。用户旧转换用的是固定 12.5 / 10 / 1，且 10 倍的两个没有贴地。
2. **静止姿态：18 系列统一为 A 字 ≈37.5°，且整条手臂是直的。** 腕→ひじ 37.2–37.8°、ひじ→手首 37.7–39.1°（肘弯 0.06–1.9°，前倾 ≈0°），肩→腕 水平 0°；源 XPS 是 T 字（上臂 0.4–2.6°、前臂前伸 15.7°、锁骨下倾 7–9°）。手臂网格被真正旋转；腿、脊柱、肩、下半身则**只改骨骼位置不改网格**（腿骨对齐成正面垂直、下半身头抬到上半身头、肩与腕同高同 Z）。あにまさ式为 29.72°/40.28°（肘弯 10.6°），用户旧转换为 45°。
3. **骨架：完整的标准骨 + 准标准骨**（全ての親/センター/グルーブ/腰/上半身1–3/首1/両目/肩P·C/腕捩1–3/手捩1–3/ダミー/親指０/足D 系/足先EX/腰キャンセル/足IK親/操作中心 全有）；IK 为 loop 40/80、单位角 1.0 rad（=mmd_tools 1.0.2 的 `ik_rotation_constraint` 默认值 → 最终 PMX 由 mmd_tools 导出）。源的 **ThighTwist 并入 足D，ShldrTwist/ForearmTwist 先并入再由准标准插件式的分段（0.25/0.5/0.75 付与，捩骨在 60% 处）重新切分**；脊柱/颈/头/胸骨的权重是源权重原样改名。
4. **下半身：源（DAZ G8）本来就有干净的 pelvis 骨——18 系列的 下半身 权重 = 源 pelvis(+hip) 权重逐顶点完全一致（Inase 14663 顶点 Σw=7069.2，Reika Σw=42318.2 = pelvis 42289.3 + hip 28.9），没有重画。** 骨位置被改成：头 = 上半身 头（低 0.004–0.007），尾巴竖直向下约 1.0–1.1 单位（≈足 高度），Z 对齐腿；父 = 腰（Y = 足 + 0.4×(下半身−足)）。上半身↔下半身 交界是一条**从 t≈0.4 到 t≈1.75 的线性渐变带**（50/50 在 t≈1.1；t 以 足 头为 0、腰节为 1），下半身↔足 交界在侧面从 t≈−2 渐变到 t≈+0.75，正中则 t<−0.75 才过渡。§5.4 给出无 pelvis 源时的构造规则。
5. **表情：固定 19 个标准名**（あ/あ２/い/う/え/お/にやり/激怒/まばたき/笑い/ウィンク/ウィンク右/びっくり/じと目/困る/怒り/真面目/上/下），无组合 morph、无材质 morph。6 个模型中 5 个是**骨骼 morph**（驱动被改名为 `QQ1`…`QQ36` 的 DAZ 面部骨，旋转量是 4° 的整数倍，位移 0.003–0.16）；Bunny 是**顶点 morph**，但每个 morph 都带 20358 个身体顶点的 1.7e-3 噪声偏移（烘焙残留）。
6. **物理（4+1 类）参数高度模板化**：身体碰撞 = 静态胶囊 18–19 个（质量 1、衰减 0.5/0.5、摩擦 0.5、组 1、不碰 1,16）；头发 = 动态胶囊（扁片后发用箱体），质量 1、衰减 **0.9/0.99**、摩擦 0、组 10、不碰 2,9,10,11,12,16，关节只给旋转 **±10°**、无弹簧，根部直接连 頭 静态体；胸 = 动态球 r≈0.6（前移 0.5），组 16 且**与所有组都不碰**，关节 ±10°、无弹簧；臀（Bunny/Tifa）同胸；衣物（仅 Reika 的胸前挂件）= 动态胶囊、组 11、只与组 1 碰。**全系列没有一个"物理+骨位置合わせ"刚体，也没有一处弹簧（Reika 例外：旋转弹簧 30）。**
7. **材质：全部统一**（TifaGantz* 被改过、除外）漫反射 1/高光 0.5/光泽 10/环境 0.5/共享 toon01/无边线/DGMS（只有 Mouth 单面）；**法线贴图放在 sphere 槽且模式=无效**（保留路径、不参与渲染）；memo 保留 XPS 渲染组与参数（`RenderGroup: 4 / Parameters: 0.1, 0, 0`）；绘制顺序 = 先 RG4 不透明、后 RG6/7 透明。同目录的 .blend 只是 mmd_tools 导入场景，**没有真正的 HD/PBR 材质**（Reika 只把 mmd 节点换成了只接底色的 Principled，法线贴图节点仍悬空且是 sRGB）。
8. **表示枠几乎是空的**（Root=操作中心、表情=空、センター=全ての親+腰），约 200–275 根可操作骨不在任何枠里；骨名 `左乳奶`/`右乳奶` 含 cp932 不可编码的"奶"，长发骨名超过 15 字节——这些是 18 系列的明显瑕疵，插件应避免。

### 4.3 结构规律（6 个 18 系列模型一致，除非注明）

- **层级**：`全ての親 → センター → グルーブ → 腰 → {上半身 → 上半身1 → 上半身2 → 上半身3 → 首 → 首1 → 頭}` 与 `腰 → 下半身 → 腰キャンセル左/右 → 足 → ひざ → 足首 → つま先`。`下半身` 与 `上半身` 都以 `腰` 为父（不是 下半身 当 上半身 的父）。`操作中心` 在第 0 位、无父。
- **腰**：R-VC（不可移动），英文名 `waist`；位置 `Y = 足Y + 0.40·(下半身Y − 足Y)`、Z ≈ +0.25。
- **腰キャンセル左/右**：父 下半身，回転付与 `腰 ×−1.0`，R--C（不显示），位置 = 足 头。
- **足D 系**（`足D/ひざD/足首D`）：放在骨表**末尾**，変形階層 **1**，回転付与 `足/ひざ/足首 ×1.0`，父链 `腰キャンセル → 足D → ひざD → 足首D → 足先EX`；**全部腿部权重在 D 骨上，`足/ひざ/足首` 本身 0 权重**（只给 IK 用）。`足先EX`：父 足首D、层 1、R-VC、无付与，位置在 足首 与 つま先 之间（Inase Y=1.033）；`つま先` 仍保留权重（Inase 2875 顶点）并作为脚趾骨（`lSmallToe*`/`lBigToe`）的父。
- **IK**：`足ＩＫ` 父 `足IK親`（`足IK親` 父 全ての親，位于踝正下方 Y=0；**Inase 的两侧 足IK親 都在 Y=0.079 且左侧没有父，是瑕疵**），目标 `足首`，**loop 40、単位角 1.0 rad = 57.3°**，链 `ひざ`（限制 X −180°～−0.5°，Y/Z 0）→ `足`（无限制）；`つま先ＩＫ` 父 `足ＩＫ`，目标 `つま先`，**loop 80、単位角 57.3°**，链 `足首`（无限制）。单位角 1.0 rad 正是 mmd_tools 1.0.2 `mmd_bone.ik_rotation_constraint` 的默认值，loop = IK 约束 iterations（`exporter.py` 第 520–524 行）→ 最终 PMX 是由 mmd_tools 导出的（.blend 中骨数 263 = 219 + 22 个付与骨×2 个影子/dummy 骨，也吻合）。参考：あにまさ式 PMD 转 PMX 后是 足ＩＫ 40 次/114.6°、つま先ＩＫ 3 次/229.2°。
- **肩**：`肩P`（R-VC，父 上半身3）→ `肩`（父 肩P）→ `肩C`（父 肩，回転付与 `肩P ×−1.0`，R--C）→ `腕`（父 肩C）。肩→腕 水平（见 §3）。
- **腕捩/手捩**：`腕捩` 父 `腕`，R-VC，**軸固定 = 腕→ひじ 方向**，位于 **腕→ひじ 60%** 处；`腕捩1/2/3` 父 `腕`，回転付与 `腕捩 ×0.25/0.50/0.75`，R--C，位于 32%/52%/72%（Bunny 为 7.6%/35.7%/63.9%）；`ひじ` 的父是 `腕捩`。`手捩` 同理（父 ひじ，60%，`手捩1/2/3` 在 32.6%/53.3%/73.9%），`手首` 的父是 `手捩`。结构与 PMXE「準標準ボーン追加」插件的产物一致（推断）。
- **手**：`ダミー`（父 手首，RMVC，无权重）；`親指０/１/２` 带ローカル軸（全模型只有拇指有ローカル軸，腕/ひじ/手首 都没有）；`人指０/中指０/薬指０/小指０` = 源的 `lCarpal1–4`（掌骨）**保留并改成"指０"命名**，有权重。

### 5.4 对插件的 下半身 构造规则（由以上实测归纳）

1. **骨位置**（与 18 系列一致，也与用户 `mmd笔记.txt` 中"下半身/上半身对齐、下半身和腿骨 Z 平齐"的经验一致）：
   - 头 = `上半身` 头（即腰节：源中脊柱第一节的头；DAZ 为 `abdomenLower`/`pelvis` 共同起点），Y 可下移 0.005 以便选取；Z = 左右 足 头 Z 的平均。
   - 尾 = 头 + (0, −1.0 × H/20.8, 0)（竖直向下，尾端约在 足 头高度；不得像 inase430 那样伸到 足 以下）。
   - 父 = `腰`（无 腰 时 = `グルーブ`/`センター`）；`上半身` 也以 `腰` 为父（**禁止 上半身 挂在 下半身 下**，clean_ik 的错误）。
   - 子 = `腰キャンセル左/右`（标准名，不要 `.L/.R`）→ 足/足D；臀/生殖/裙子根骨直接挂 下半身。
2. **权重来源判定**（按优先级）：
   - (a) 源有"腰节起、向下"的 pelvis/hips 骨且其权重的 w>0.5 部分 Y 中位数在 [足Y − 1.0L, 上半身Y + 0.3L] 内 → **原样改名/合并**到 下半身（18 系列做法；DAZ `pelvis+hip`）。同时测它与脊柱权重的 50/50 高度：若比腰节高出 >0.5L（Bunny 类 Rigify 源高出 ≈1.1L），提示用户把 上半身/下半身 头上移到该边界或改走 (b)。
   - (b) 源把髋部权重放在 root/hips 且该骨同时覆盖下腹（如 inase430 的情况：w>0.5 中位数高于 上半身 头）→ **按高度切分**：对该骨每个顶点，`w下半身 = w × S(t)`、`w上半身 += w × (1−S(t))`，S 为 smoothstep，S(0.5)=1、S(1.75)=0（50% 点 ≈ t 1.1）——复现 DAZ/18 的上半身↔下半身渐变带。
   - (c) 源完全没有髋骨（腿直接挂脊柱、髋部权重在最低脊柱节上）→ 同 (b)，切分对象换成最低脊柱节；足↔下半身 交界保留源腿权重不动。
3. **验收检查**（建议做成校验项）：下半身 nV>0；Σw/nV 在 0.4–0.8；w>0.5 顶点 Y 中位数在 足头 与 上半身头 之间；t ≥ +1.75（≈上半身头上 0.8L）以上 下半身 权重 ≈0（Rigify 类源允许例外但要提示）；侧面 t=0 处 下半身/足 ≈ 50/50；正中 t∈[−0.5, 0.5] 下半身 ≥ 0.8；`上半身` 与 `下半身` 的父相同。

### 7.2 骨骼 morph 的构造

- 驱动骨 = 源面部骨（DAZ 的 `lowerJaw`→`Jaw Bone`、`lLipCorner`→`QQ26`、`lEyelidUpper`→`QQ12` 等，§4.5），**不新建控制骨**；Teeth/Tongue 只在 お 里少量位移。
- **旋转量全是 4° 的整数倍或其组合**（4、8、12、16、20、24、36、48°；14.4°=√(12²+8²)、21.5°/25.3° 为两轴组合；Jaw 4.8/6.7/6.2 为微调），位移 0.003–0.20 单位——明显是在 PMXE/Blender 中按固定步长手调的。
- 典型配方（Inase18）：
  - あ：Jaw Bone 绕 X 转 −4.8°（あ２ −6.7°），嘴角 QQ26 上移 0.07，唇骨上下微移 0.004–0.006。
  - まばたき：上眼睑 QQ12 转 21.5°（X −20°，带 Y/Z 分量）并下移 0.048、内眼角 QQ7 转 20°；Czern 用 48.6°（其上眼睑骨轴向不同）。
  - 笑い：26 根骨——上睑 12°、下睑 QQ13 上推 0.10、眼角 QQ10 转 8°、颊 QQ17 上移 0.054、眉/鼻唇沟小位移。
  - 眉系（困る/怒り/真面目/上/下）：眉骨 QQ1–QQ4 上下 0.04–0.14，怒り/真面目 叠加 8° 旋转。
- TifaGantz* 的 あ/あ２ 只动 Jaw Bone（8°/11.2°），说明配方随源面部骨架而变（FF7R 源唇骨不同）。

### 7.3 顶点 morph（Bunny18）

- 19 个都是顶点 morph（与骨骼 morph 同名同序），有效偏移（>0.01）顶点 1378–12709 个，最大位移 0.03–0.24。
- **但每个 morph 都额外包含 20358 个身体顶点（Y≤16.5，含腿）的约 1.7e-3 恒定偏移**（offsets 总数因此达 22k–34k）——典型的"由骨骼姿态/形态键烘焙成顶点 morph 时基形不一致"的残留；视觉上不可见，但膨胀文件、并会在表情叠加时让身体轻微漂移。插件生成顶点 morph 时应以 1e-4×H 左右阈值裁掉微小偏移。

### 8.6 评价（供插件取舍）

- 18 系列物理是"**能用的最低配置**"：参数几乎全是常量模板（身体=PMXE 默认值；头发 0.9/0.99、±10°、无弹簧；胸 r0.6、全不碰、±10°、无弹簧），没有按长度/质量分级（质量全 1，链尾与链根同质量）。
- 头发衰减 0.9/0.99 + ±10° 使发链很"硬"、摆幅小；胸部动态球无弹簧，在 MMD 中会沉到限位下沿而不是回弹（Reika 用了旋转弹簧 30，更合理）；胸与任何东西都不碰撞 → 不会被手臂推开，但也不会穿模报错。
- 没有 dyn+bone：长发链根段若是纯 dynamic，在大幅动作下根部可能被拉离 頭——Reika 用"根段组 2 且不碰身体"来缓解。
- 衣物物理几乎空白，裙子/外套预设无法从本系列取得，需参考 `06_材质表情物理与校验.md` 与 `10c_物理插件组.md` 的社区参数。

### 9.3 绘制顺序规则

18 系列：**先渲染组 4（不透明），后渲染组 6/7（带 alpha）**；同组内基本按名称排序（`+` 可选件 → `-` 备选件 → 身体部件字母序）。实测例外：Reika 把 `-Pubes`(RG4)、`-Suit B|Chest`(RG4) 排在透明组之后；Bunny 的 `Brows`(RG7)、`Eyelashes`(RG7)、`Eyes`(RG5) 插在中间、`+Helmet.2`/`+Visor`(RG7) 和两种发型在最后。
→ 规则可写成：按 XPS 渲染组是否带 alpha 分两段——XNALaraMesh `xps_material.py` 中 `rgAlpha=True` 的组为 **6, 7, 8, 9, 12, 15, 18, 19, 20, 21, 23, 25, 27, 29, 31, 33, 37, 39, 41, 43**——带 alpha 的放后，组内保持 XPS 网格原顺序；睫毛/眉/发/透明面罩可再额外后置。

→ 18 系列的 .blend 是"PMX 再导入 Blender 用来渲染/调物理"的场景，**没有可以直接复用的 HD 材质模板**。用户本机已有的 `roe_game_materials` 等插件（见 `10_本机已有插件工具箱.md` §4）才是 HD 回挂的参照。

### 9.5 对"重新导入 PMX 后回挂 HD 材质"的启示

1. PMX 里能可靠拿到的：材质名（= XPS 网格名去前后缀，可回溯到源 XPS 网格）、漫反射路径、**sphere 槽里的法线路径（模式 0 时视为"携带的法线图"，不是 sphere）**、memo 里的 XPS 渲染组号与参数（RG 决定 alpha/双面/有无高光图/法线强度等）。
2. 回挂时需要做而 18 系列 .blend 没做的：法线图节点改 **Non-Color** 并经 Normal Map 节点接入（DAZ 系 `_N`/`NM` 为 OpenGL，Reika 文件名直接带 `_OpenGL`）；按文件名后缀在源目录补找 `Roughness/Metallic/Emissive/AO/Spec`；RG 6/7 等透明组设 Alpha Blend/Hashed 与阴影模式；Mouth 等单面材质保持背面剔除。
3. 回挂不应改动 `mmd_material` 的数值（导出 PMX 时仍用 1/0.5/10/0.5/toon01 那一套），只替换/并联 Blender 着色节点——这样同一个 .blend 可以既渲染 HD、又无损再导出 PMX。

## 13. 对插件默认值的建议

下面每条都标注依据（§ 指本文小节）。"H" = 导出后 PMX 总高；凡写成绝对值的长度，均按 18 系列的典型 H≈20.8 给出，实现时按 `× H/20.8`（或按肩高比例）缩放。

### 13.1 尺度

| 设定 | 默认 | 依据 |
|---|---|---|
| 缩放方式 | **"肩线高度归一"**：贴地后令 `腕` 头高度 = **17.0** PMX 单位；即 `总因子 s = 17.0 / (源 lShldrBend 类骨头高度 − 源最低顶点高度)`（XPS 单位）。在 Blender 中实现为：先把模型缩放 `s / 12.5`（即 Blender 里肩高 = 17.0×0.08 = 1.36 m），再用 mmd_tools 默认 12.5 导出 | §2.2：6 个 18 系列模型 腕 高 16.99±0.04（CV 0.22%），总高/头顶都不一致；配对因子 10.94/11.42/12.22 均落在此规则上 |

### 13.4 下半身（无干净 pelvis 时的构造规则）

见 §5.4，要点：头 = 上半身 头（下移 0.005）、Z = 足 头 Z；尾竖直向下 1.0×H/20.8；父 = 腰，与 上半身 同父；子 = 腰キャンセル左/右 + 臀/生殖/裙根。权重：有"腰节起向下"的 pelvis/hips → 原样合并（检查与脊柱的 50/50 边界是否在腰节 ±0.5L 内）；否则对 root/hips/最低脊柱节按 `t=(y−足Y)/(上半身Y−足Y)` 做 smoothstep 切分（S(0.5)=1、S(1.75)=0，50% 点 t≈1.1），足 侧保留源腿权重。验收：Σw/nV 0.4–0.8、w>0.5 顶点 Y 中位数在 足头 与 上半身头 之间、t≥1.75 处 ≈0、侧面 t=0 处 下半身/足 ≈ 50/50。

### 13.9 表示枠与校验

- 表示枠：`Root`=全ての親（或 操作中心）、`表情`=全部 morph、`センター`、`ＩＫ`、`体(上)`、`腕`、`指`、`体(下)`、`足`、`髪`、`胸/物理`、`その他`——**不要照 18 系列留空**（§10）。
